  # Privacy Policy for AI Moderation Copilot

  Last updated: May 18, 2026

  AI Moderation Copilot is a Chrome extension that provides reviewer-led policy
  and PBR consultation support for content moderation workflows.

  ## Data We Collect

  The extension collects information manually entered by the user, including
  selected policy IDs, ASR or transcript text, reviewer-provided context,
  consultation questions, and an access code used to authenticate with the
  Copilot backend.

  The extension does not automatically read web page content, browsing history,
  media, location, mouse activity, scrolling activity, or keystrokes. It does
  not write data back to any moderation system.

  ## How We Use Data

  User-provided inputs are sent to the Copilot backend API to generate advisory
  policy consultation responses. The access code is used only to authenticate
  requests to the backend.

  AI Moderation Copilot provides advisory support only. Final moderation
  decisions remain the responsibility of the human reviewer.

  ## Data Sharing

  User-provided inputs may be processed by the Copilot backend and the
  configured AI model provider solely for generating policy consultation
  responses.

  We do not sell user data. We do not use user data for advertising,
  creditworthiness, lending, or purposes unrelated to the extension's single
  purpose.

  ## Data Storage

  The extension stores the access code locally in Chrome extension storage so
  the user does not need to re-enter it each time.

  By default, the extension does not store ASR text, reviewer-provided context,
  consultation questions, or model responses locally as user history.

  The backend may process request metadata such as request time, selected policy
  IDs, request type, latency, and error code for debugging, reliability, and
  usage monitoring. Raw case content is not intended to be retained by default.

  ## Security

  Requests to the Copilot backend are sent over HTTPS. The model API key is
  stored only on the backend and is not exposed in the Chrome extension.

  ## User Control

  Users can remove the extension from Chrome at any time. Users can also clear
  extension storage from Chrome settings to remove the saved access code.
